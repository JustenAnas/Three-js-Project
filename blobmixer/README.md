# 🎨 Blobmixer - Interactive 3D Blob Playground 🌐

Welcome to **Blobmixer**, an experimental 3D graphics playground showcasing interactive blob animations, dynamic shaders, and real-time visual effects. 🚀

Explore creative web design with **Three.js**, **GSAP**, and **Vite**.

---

## 🌟 Features

- 🖼️ Interactive 3D Blob Animations  
- ✨ Real-time GLSL Shaders for stunning visual effects  
- 🎢 Smooth Animations powered by GSAP  
- 🖱️ Hover and mouse interaction effects  
- 🌐 Fully responsive design  
- 🎨 Modern and immersive UI  

---

## 🚀 Technologies Used

- **HTML5**: Structure and content  
- **CSS3**: Styling and layout  
- **JavaScript**: Core functionality & animations  
- **Three.js**: 3D rendering & blob animations  
- **GSAP**: Smooth and efficient animations  
- **GLSL Shaders**: Custom vertex & fragment shaders  
- **Vite**: Fast development server and build tool
